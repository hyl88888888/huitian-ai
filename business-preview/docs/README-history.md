# 回天 · 工作台（商业版预览）

这是独立于 `D:\HuiTian` 自用版的新产品线。当前版本是 0.1.0 开发预览，不是已经通过商用验收的发行版。

## 产品原则

用户表达目的，模型输出结构化目标和任务计划；执行器调用本地能力，结果经核验后交付。
不通过硬编码用户句子、同义词表或正则句式选工具。不使用付费云模型，也不依赖用户的 Codex 账号。

普通 Windows 电脑是主力设计目标。商业版统一一个执行核心，不按电脑配置分配不同模型。文件工具可以独立工作，不要求启动模型；自然语言入口仅使用固定的 2B 本地模型。不能从本机 CPU 模式测试推导“所有电脑、所有任务都准确”。

## 独立目录

- `Project`：源代码与测试。
- `Releases`：可运行程序。
- `Runtime`：便携本地推理组件；默认纯 CPU，不携带 CUDA 大型运行库。
- `Models`：本地小模型。与原自用版完全隔离，不下载原 27B。
- `Data`：本地会话、应用索引、浏览器独立资料目录。
- `Outputs`：任务产物；修改已有文件默认生成副本。
- `Logs`：运行与性能记录。
- `Cache`：依赖、临时文件与测试资源。
- `Licenses`：随分发许可证。

不会复制自用版的聊天记录、联系人、密钥、浏览器登录资料或模型。系统对话框、字体、证书等少量 Windows 管理的数据可能仍在系统盘，项目可控的大型资源都在产品目录。

## 当前实现路线

1. 原生 WPF 工作台，不引入整套 Electron 运行时。
2. llama.cpp 本地推理；固定 Qwen3.5-2B Q4_K_M，文字模式、不装视觉投影、不自动加载语音模型。它是辅助理解组件，不承担文件格式处理、应用协议、参数校验等确定性工作。
3. 单次语义理解并输出计划，有限观察/恢复；全流程可取消，审批在执行边界强制实施。
4. Office 用微软 Open XML SDK，不依赖付费 Office 安装，也不模拟几十次鼠标点击。
5. 网页用 Playwright 读取 DOM，优先使用已安装的 Edge/Chrome，以独立资料目录运行。不得偷偷连接已有浏览器会话。
6. Windows 原生控件工具支持发现窗口、激活、有限控件树、填写并回读、提交点击/选择；只使用刚观察到的编号，超时隔离。自绘或未提供辅助功能接口的软件仍需后续适配。
7. 自用版中未经端到端验证的自动聊天不直接复制为商业版“已支持”功能。

## 开发

使用已有 D 盘 SDK：`D:\HuiTian\Runtime\DotNetSDK\dotnet.exe`。先运行 `scripts/Use-BusinessEnvironment.ps1` 将缓存定位到商业版目录，再编译。运行时不依赖该 SDK，也不引用自用版项目。

`scripts/Install-Models.ps1` 下载固定 2B 模型并做 SHA256 验证。下载源失败会保留断点，不覆盖已有不同内容模型。4B 试验候选已按用户要求删除，不在商业版下载或分发清单中。

`scripts/Publish-Business.ps1` 生成无需客户安装 SDK 的 Windows x64 成品。`scripts/Export-CleanPreview.ps1` 可导出不含个人会话、密钥、浏览器资料或测试数据的干净预览包；不要直接把整套开发目录交给客户。

## 不能夸大的内容

“预览版能创建一个文件”不等于能够完成任何办公任务。“浏览器打开了”不等于任务完成。
没有真实送达核验，不能声称已发送。模型编造的网址、路径、表格内容不能冒充已取得的事实。
登录、验证码、支付、账号安全必须有用户参与；普通浏览器打开不该被当成登录接管。
发布、上传、对外发送等需要可审计的权限策略。原始用户文件默认不覆盖。

详细方案见 `docs/商业版实施方案.md`；跨生活、学生、办公、沟通等领域的工作流及缺口见 `docs/通用执行能力矩阵.md`；本轮测试与未完成边界见 `docs/验收记录.md`。
