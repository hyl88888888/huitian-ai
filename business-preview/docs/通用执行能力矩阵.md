## 4. 多会话、多人聊天与桌面共享必须补齐的状态

### 4.1 会话独立不是只分开聊天窗口

现有本地会话独立解决的是“用户在工作台新建对话后，旧任务结果不能写到新对话”。它不证明第三方服务中的联系人、账号、浏览器会话和授权已经隔离。

每个长期任务至少需要独立保存以下信息，状态不能以联系人显示名或窗口标题作为唯一键：

| 状态域 | 必需内容 | 不满足时的行为 |
| --- | --- | --- |
| 身份 | `taskId`、工作台 `conversationId`、平台、账号稳定 ID、对方稳定 ID/群 ID、必要的群内说话人 ID | 同名联系人、账号切换或无法确认身份时停止发送并补充定位，不猜收件人。 |
| 目标与约束 | 当前目标、主题、禁谈内容、允许透露的信息、用户最新否定、附件白名单 | 最新约束优先；不把网页或对方消息中的“忽略用户”视为授权。 |
| 时间 | 独立 `startedAt`、`deadline`、时区、明确的时长是否计入等待、停止原因 | 甲 10 分钟、乙 30 分钟各自计算；不得共享一个全局倒计时。 |
| 无时长状态 | `deadline=null`、持续到用户停止或需接管的约定、最后活动时间 | 不偷偷套用其他联系人的时长；也不把无时长解释为无限内容/无限收件人的发送授权。 |
| 入站证据 | 平台会话 ID、消息 ID/可靠等价标识、说话人、时间、内容指纹、观察时间、最近处理游标 | 只有未处理的对方新消息才能触发回复；不能把自己发出的消息或历史回流当新消息。 |
| 出站账本 | 草稿、获准的最终内容/附件、收件人、动作编号、提交前证据、提交状态、回执 | 提交结果未知时观察恢复，禁止直接重发；只有文字回读不能标记为发送成功。 |
| 生命周期 | 运行、等待、到期、停止、需人工、结果未知；最后检查点与恢复规则 | 用户停止后取消排队写入；重启不自动重放未知状态的发送/下单。 |

“一直帮我聊”不能由一个无退出条件的忙循环实现。需要可中断等待、退避、离线与休眠处理、有限观察频率，以及每次恢复前的身份和授权核验。联系人没有新消息时保持等待；不能为了显得活跃而编造对方回复或自行增加频繁外发。

### 4.2 桌面单写锁

当前除适配器实例内序列化外，`DesktopSessionGuard` 已按 Windows 登录会话提供跨进程命名 mutex：激活窗口、UIA Invoke/Select 和填写均经过单写互斥。超时、提交后取消/异常或写进程异常退出会设置共享隔离事件及持久标记，新任务和新进程不能自动绕过；恢复须人工核对，不自动清标记。这解决了桌面原子写入互斥与不确定结果隔离，不等于整条业务公平调度。还需在现有基础上补齐：

1. 对全部共享资源明确调度范围。已纳入保护的原生桌面写入跨窗口/进程共用互斥；独立浏览器目前有自己的串行和审批边界。后续剪贴板等新增路径以及跨表面复合任务还需统一规划，不能宣称已覆盖所有软件的共享状态。
2. 将原子写入互斥扩展为必要的业务级租约：“获取租约 → 重新观察账号/窗口/联系人 → 绑定元素与最终参数 → 执行动作 → 读取业务结果 → 保存证据 → 释放租约”。当前真实审批上下文/参数已绑定并在动作前复查，但联系人身份、业务回执及整段事务仍须实现，不能让不同任务随意穿插观察与发送。
3. 纯粹阅读也要考虑会使快照失效的导航、窗口枚举和选择变化；当前重新列窗口/读取控件可能清空临时编号，不能跨任务复用。
4. 用户手动换窗、平台切账号、控件身份变化或编号过期时作废租约和快照，重新观察。禁止猜坐标或沿用过期编号。
5. 保持现有持久隔离规则：UIA 超时或提交后的取消/异常可能产生迟到动作，不自动重试写入，不新开替代任务、进程或工作线程绕过。后续补充人工核验后的显式恢复流程，并保留处置证据。
6. 读多写一的调度必须兼顾公平与期限，不能因一个人持续有新消息就让另一个人的截止与取消失效。

### 4.3 授权、付款、验证码与合法来源

- 授权应绑定对象、动作、最终内容/附件、数量、金额与期限等相关字段。已授权范围要持久保存；不是每次重复问同一句，也不能把批准一次点击扩展为任意购买、联系人或未来内容。
- 支付密码、短信验证码、平台验证、登录凭据、会员购买及付款由用户在合法界面完成。代理可以整理待核对信息并在用户处理后重新观察状态，不能读取/猜测验证码或绕过验证。
- 外卖/购物的“已下单”“已支付”“已取消”“退款到账”是不同状态。招聘的“已填表”“已提交”“已投递成功”不同；聊天的“已输入”“已发送”“已送达”“已读”不同。各状态必须用对应证据命名。
- 音乐影视只使用用户有权访问的合法来源。版权、会员、地区或年龄限制是流程条件，不通过盗版链接、绕过 DRM 或付费墙达到目标。
- 默认验证使用自建页面/窗口、模拟账号和临时文档。不得为自动测试向真实联系人发消息、真实投递、真实下单或扣款。
